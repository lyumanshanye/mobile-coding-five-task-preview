sensor-readings.png与sensor-readings.csv描述相同的三条虚构测量记录，标识ORBIT-26。这是本地生成的原创测试素材，不是真实设备或人员数据。图片800x520，包含可辨认编号、数值及红绿蓝色块，方便检查选错文件、空白渲染或不完整恢复。CSV使用显式列名及十进制数据。
