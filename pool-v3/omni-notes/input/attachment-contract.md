# 图片与文件附件：已核验子链

已归档的清单仍可编辑并添加附件。通过系统文件选择器选择input/media中的PNG和CSV后，两份附件应属于原清单，保留标题、条目顺序、各项完成状态和归档状态；不能复制或重建整条笔记作为添加附件的替代。

图片缩略图可以裁剪，但打开图片时应能查看完整内容，包括三条测量记录、数值和ORBIT-26-A标识。不能以一个同名占位图或不可打开的缩略图代替附件。通用文件须保留完整原始内容；名称是可见标签，不是唯一对象身份。

返回保存并终止进程后，附件引用和数据须持久化。实现可以复制文件或合法持久化访问权限，不要求采用参考App的私有路径、内部重命名或数据库结构。原文件内容、附件归属和用户可见行为才是判定对象。

参考App在内部将图片统一分类为image/jpeg，即使原始文件实际是PNG；这不是候选必须复制的格式要求。实际编码应按文件内容处理，不能因为这个内部分类而把PNG错误解释成JPEG。系统文件选择器的Gallery入口与App的Files入口也不能混淆。

含附件的已归档清单移入回收站、终止进程再恢复后，仍应是原来的已归档清单，保留条目状态、附件归属和完整附件内容。不得通过新建同标题笔记或空附件模拟恢复。

证据覆盖两文件选择、图片实际显示、保存重启后的附件展示，以及含附件回收往返后的对象身份、状态和实际文件字节。后续已从Archive打开恢复后的清单，再次打开完整图片查看器并返回原清单，确认三条测量记录与ORBIT-26-A标识完整可见。CSV外部查看器、删除原源文件后的可用性、附件移除、同名文件和备份恢复仍未完成验证，完整NT-03/NT-08不因此视为已验收。
