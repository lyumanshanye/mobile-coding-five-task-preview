# 离线有声书书库与播放状态

状态：构题草稿，未冻结。参考 GitHub Voice 8.9.0，交付完整可运行的 Android 有声书 App。不是只显示播放按钮和进度数字的模拟播放器。

用户通过系统目录授权导入书库，在章节之间跳转和定位，为不同书籍保存独立播放位置与书签。切换书籍、返回后台、暂停、重启和重新扫描后，媒体身份与状态必须保持一致，并产生真实音频输出。

| ID | 业务要求 | 可观察结果 |
| --- | --- | --- |
| AB-01 | 使用系统目录授权选择书库，取消时不产生伪书籍 | 权限和扫描结果对应实际文件，权限失效可恢复，不靠固定路径绕过授权 |
| AB-02 | 支持父目录内每个子目录一本书、单个目录一本书及作者/书籍两层目录模式 | 同一组文件在不同模式下分组正确；根目录直接音频文件作为独立书籍。模式切换与重复导入语义待核验 |
| AB-03 | 按章节组织并播放真实媒体，显示章节/整书位置 | 同名章节在不同书中不混淆；章节顺序、文件名与元数据优先级需冻结 |
| AB-04 | 播放、暂停、前后跳转、拖动定位和跨章节连续播放 | 音频内容、播放器状态、时间进度一致；不能只改变界面计时器 |
| AB-05 | 每本书保留独立播放位置，切书再返回、force-stop后恢复 | 书籍身份稳定，进度不串书；完成书籍边界行为按原版核验 |
| AB-06 | 创建、改名、跳转和删除书签 | 书签绑定书籍、章节和位置；同名书签可区分；跳转后音频内容与位置一致 |
| AB-07 | 改变播放速度，配置睡眠定时并在结束后继续播放 | 速度影响真实媒体推进；定时触发暂停，暂停后不继续出声；允许误差与淡出语义须实测冻结 |
| AB-08 | 前后台切换、系统媒体控制及音频焦点变化 | 页面、系统媒体会话和真实播放保持一致；具体焦点/耳机策略需冻结 |
| AB-09 | 重新扫描书库及处理不可用媒体 | 不重复创建同一书籍，已有进度不无故丢失；损坏或移除文件不导致永久卡死 |
| AB-10 | 多屏幕、深色、字体放大和旋转下保持可操作性 | 章节列表、书签、进度控件可用，旋转不产生双重播放 |

正式夹具将包括多本多章节、跨书同名章节、不同长度音频和可识别音频内容，带时长与内容清单。必须验证真实音频流，不能以时间数字、播放图标、MediaSession存在或日志中的play作为输出证据。

本题不包括在线听书、付费资源及 Android Auto。原仓库说明 Auto 需要 Play 审核发行版，而本批使用 GitHub flavor；不能把不同发行渠道的能力默认为参考行为。

已提供五个可解码、非静音的本地 MP3 夹具及书库、章节页面参考截图，文件清单见 input/README.md。这些材料仅覆盖部分导入与章节选择状态，不证明真实播放。当前尚缺完整设计图、真实音频采集验证、平台媒体策略和时间容差，草稿不可正式交给模型。
