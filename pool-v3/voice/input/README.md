# 本地语音夹具 v01

设备导入入口为 `audio-v01/library/`。音频为本次原创虚构旁白，用本机 FFmpeg/libflite 的 slt 合成音色生成，没有联网下载录音。公开输入仅提供媒体文件，生成工具与内部验证记录不属于作答输入。

| 书籍/章节 | 解码时长（秒） |
| --- | ---: |
| Field Journal / 01 Arrival.mp3 | 32.470 |
| Field Journal / 02 Return.mp3 | 33.170 |
| Weather Notes / 01 Arrival.mp3 | 31.530 |
| Weather Notes / 02 Return.mp3 | 33.500 |
| Station Log.mp3（根目录单文件书） | 30.925 |

均为 MP3、单声道、24000Hz、64kbps，写入 title/album/track 元数据。两个目录具有相同章节文件名但不同旁白，能够检查书籍身份和章节误串；根目录文件用于核验独立单文件书识别。

5个文件均已完整解码并检查为非静音。导出包中的 `public-manifest.json` 记录每个公开文件的SHA256及字节数。以实际媒体元数据为准，不要硬编码上述文件名、章节数或时长；界面显示秒数可以按正式题面规定舍入。

这些是示例素材，不是预期输出或播放验收结果。正式音频捕获容差仍待设备校准；本题仍为草稿，尚不具备完整播放Golden。
