# 离线项目笔记工作台

状态：构题草稿，未冻结、不可提交模型正式评测。原版行为核验与设计证据尚未齐全。

实现一个可安装运行的 Android 本地文档 App。使用者在离线野外调查中维护多个项目，每个项目有说明、采样记录和行动清单。文件必须是真实 UTF-8 文本，不能只保存在界面内存中，也不能把参考截图作为不可交互背景。

参考对象为 Markor。交付应包含完整可编译工程和 APK，而非单页演示、网页截图或针对示例内容写死的输出。公开夹具只是示例；验收将改变文本、目录名、文件数量和操作次序。模型正式工作区不提供原版源码、Git 历史、隐藏测试或参考实现。

## 用户流程

用户选择一个本地笔记目录，浏览文件夹，打开一份调查报告，修改 Markdown，在预览中确认排版并进入关联记录。随后查找某个样本编号，修改多处观测数据，通过撤销恢复误改，再保存。退出和重启 App 后，目录、正文、预览及真实磁盘文件应保持一致。另一个目录下的同名记录不能被误改。
