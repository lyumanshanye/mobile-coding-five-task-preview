# 待办：多级清单、重复任务与筛选一致性

## 用户目标
准备一场社区活动，在同一清单里拆分采购子任务、安排重复检查，并在搜索/标签过滤与重启之间保持准确状态。

在Android端实现以下可交互工作流。参考应用是设计与功能来源，不要求复刻全部应用。

## 输入与初始状态
input/seed.json给出固定ID、父子关系、标签、截止时间及测试时钟。可提供仅调试构建可用的导入入口，也可操作创建；不得由UI展示seed文件本身冒充清单。全部本地，无网络账户要求。

## 需求

### R1
清单、任务编辑页展示标题、截止时间、优先级、标签及子任务；允许增删改，不把嵌套数据压成只读文本。

来源：reference_documented；对应图：S01, S04。

### R2
以input/seed.json建立活动清单与三个子任务；父任务完成前须提示仍有未完成子任务，允许取消并保持状态。该提示策略是本题新增。

来源：synthetic_extension；对应图：S01。

### R3
重复任务每周一09:00（Asia/Shanghai）；完成2026-10-19实例后下次截止为2026-10-26 09:00。撤销完成恢复原实例，不叠加生成。

来源：synthetic_extension；对应图：S01。

### R4
按标签采购与未完成筛选，编辑子任务标签/完成状态后列表即时变化；清空筛选后完整恢复，重启不丢数据。

来源：synthetic_extension；对应图：S04, S05。

### R5
深色/浅色主题切换保留筛选及编辑中的内容；未保存返回可丢弃或继续。无需接入真实账号、同步或定位服务。

来源：synthetic_extension；对应图：S04。
