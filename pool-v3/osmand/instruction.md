# 轨迹地图：GPX分析、航点筛选与视图联动

## 用户目标
导入一次徒步的GPX，查看轨迹与海拔变化，在地图和航点分组之间切换，并编辑补给点后保存与恢复。

在Android端实现以下可交互工作流。参考应用是设计与功能来源，不要求复刻全部应用。

## 输入与初始状态
input/walk.gpx包含6个带时间和海拔的轨迹采样、3个分组航点；input/local-map.osm仅包含同一区域的6个节点与一条名为Fixture Walk的合成步行道路（highway=footway），不含公园、多边形或周边道路，不是实际地理权威数据。允许在中性底色上渲染此本地道路、轨迹与航点，不要求复刻参考图的真实街区底图。input/broken.gpx故意截断。可使用成熟GPX/XML解析器与地图渲染库；输入全部本地，不需外部地图下载。

## 需求

### R1
从系统文件选择器导入GPX，地图展示轨迹与3个航点；概览展示文件名、距离、海拔范围，禁止只显示静态截图。

来源：reference_documented；对应图：S01, S02。

### R2
海拔图沿轨迹距离排列；选择图中采样点时地图定位该坐标，切换回概览后保持选点。

来源：synthetic_extension；对应图：S04, S02。

### R3
航点按补给/观景分组筛选，列表与地图同时变化；切换全部恢复3点；编辑补给点名称与描述，返回地图仍显示新名称。

来源：synthetic_extension；对应图：S03。

### R4
导出GPX后再次导入，坐标、海拔、航点名称描述保持；坏XML导入失败，已有轨迹和选点保持不变。

来源：synthetic_extension；对应图：S02, S03。

### R5
地图支持平移缩放，重新居中能够显示完整轨迹；离线底图由本地OSM数据渲染，不接入真实定位、路由或在线瓦片。

来源：synthetic_extension；对应图：S01。
