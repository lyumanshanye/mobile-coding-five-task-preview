# 每七天三次：二值计划的派生状态与强度

本契约限定frequency=[3,7]的二值计划。它与每日数值契约不同，不适用于月计划、多日数值目标或所有频率的通用推断。连续记录、周/月图表聚合及修改周期的完整行为仍须补齐。

## 原始状态与派生状态

按habit_id与日期保存用户原始记录：yes表示实际完成，no表示显式未完成，skip表示主动跳过；没有记录的日期为缺失。备注属于原始日期记录。同名习惯不能共享数据。

派生状态另含rest，表示该日期处于计划允许的自动休息区间。rest不能写回替换原始记录，也不能计作用户实际完成。原始no或缺失日期都可能在界面和派生导出中呈现rest，但两种原始状态仍要能区分。原始yes、skip及备注不因休息区间改变而丢失。

## 自动休息区间

按日期升序取全部实际完成日期。每三个相邻的完成日期组成候选组：最早为a，最晚为c；若c-a小于7天，生成区间[a,a+6天]，并记锚点c。这里按滚动日期计算，不在自然周的周一或周日清零。

把候选区间按起点从新到旧处理。最新区间不移动；每个更早区间与前一个已经处理的较新区间比较：若较早区间的终点e不早于较新区间的起点b，向过去平移min(e-c, e-b+1天)，其中c为该较早区间的锚点。平移只调整起点和终点，锚点及用户完成日期不变。否则不平移。

所有最终区间取并集。区间内，原始yes仍为yes，原始skip仍为skip，其余日期派生为rest；区间外保留原始no/yes/skip，未记录日期仍缺失。备注从原始记录保留，自动补出的日期备注为空。区间可能覆盖最早记录之前或当前日之后，这些都是派生状态，不能伪造为用户输入。

## 强度计算

从最早派生或原始已知日期开始，初始强度s=0。对每个自然日d，统计[d-13天,d]内实际完成的次数k，完成比例p=min(1,k/6)。自动休息、显式未完成和缺失都不增加k，跳过也不增加k。

令m=0.5^(sqrt(3/7)/13)。非skip日更新s=m*s+(1-m)*p；skip日沿用前一天强度，但日期窗口照常向前推进，不能从时间轴删除跳过日。内部保留精度，仅在展示或导出时按规定精度舍入；本参考CSV分数使用四位小数。

强度输出到冻结的当前日期为止。派生状态导出可能包含区间延伸到的未来休息日，不表示未来已有用户记录。原始记录导出与派生状态导出应明确区分；参考App的YES_MANUAL/YES_AUTO等CSV字符串不是候选必须采用的内部编码。

## 验证范围

已用Training的跨月原始历史核对真实App导出的全部逐日强度、派生状态及备注，并另行核对持久化原始记录没有被自动休息覆盖。源码规则及独立计算器还覆盖稀疏历史、区间平移和滑动窗口边界；这些额外算例是计算器测试，尚非独立设备样例。

另已实际将Training的2026-10-15从yes改为skip，保留备注，重启后核对全部22天强度、22条派生状态及全部习惯的89条原始记录。实际完成数由10变为9，10月16日强度由0.3671变为0.3389，10月17/18日原有未来休息不再导出。修改历史必须重新计算受影响区间，不能仅改变当天图标。

尚未完成的设备验证包括空历史、独立稀疏样例、周期编辑、连续记录与自适应布局。不能把当前导出交叉核验视为完整HB-04/HB-05验收。
