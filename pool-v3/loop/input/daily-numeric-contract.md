# 每日数值习惯：已验证的业务规则

本文件只定义周期为每日一次的数值习惯。完整题目仍需每周二值计划、连续记录、聚合图表和目标变更规则；本文件不缩减这些要求，也不能单独视为完整任务规格。

## 原始记录与身份

使用history.json中的habit_id和ISO日期共同标识一条原始记录。两个同名习惯必须独立。日界为UTC自然日，日期不能随系统显示语言改变。未出现的日期是未记录；value且数值为0是显式零；skip是跳过。三个状态必须在存储、编辑、展示和导出时保持区分。value记录的数值与notes同时保存；修改数值不应改写备注。

每日数值习惯的计算窗口只有当天。对正数目标T，至少目标的完成比例为min(1, v/T)，至多目标为max(0, min(1, 2-v/T))。v为当天非负数值。目标T=0时，至少目标完成比例为1；至多目标在v=0时为1，v>0时为0。

未记录日期在强度计算中使用v=0，但不能因此生成一条零记录。跳过日期不更新强度，沿用前一天结果。二者在至多目标下可能暂时显示同一分数，但不能互相替换。对数值习惯，是否达到目标和连续完成记录的完整规则仍待补充，不可将本文件的比例直接当作所有视图的完成标记。

## 强度递推

令m=0.5^(1/13)。从该习惯最早的显式记录日期开始，每个自然日更新s=m*s+(1-m)*p，其中p为上述完成比例。至少目标的初始s为0，至多目标为1。跳过日期保持s不变。内部保留计算精度，仅在导出分数时四舍五入为四位小数；不得每天先舍入再递推。

历史更正必须重新计算被更正日期及之后的派生结果。早于更正日期的结果不变。保存后force-stop再打开，原始记录和重新计算结果均应保持一致；不能仅修改当前图表缓存。

算例：每日至多2杯，从初始强度1开始，某日记录4杯，则完成比例0、当天强度约0.9481；次日记录1杯，完成比例1、强度约0.9508。若第二日是skip，则保持第一日强度。未记录与显式0在该目标下完成比例都为1，但只有显式0应该导出原始记录。

## 编辑与导出

编辑同一习惯同一日期应更新这一条记录，不得追加重复日期；更正不影响其他习惯或日期的原始记录。导出须可辨别习惯身份、日期、未记录/零/跳过、原始数值和备注。原版CSV的私有编码不作为候选App必须采用的格式；候选输入/输出适配协议仍待冻结。

## 已有历史下的目标变更

每日数值习惯保存新目标后，已有历史的强度按当前目标从最早显式记录重新计算，不以修改目标的日期切分新旧算法。已有原始记录的日期、数值、跳过状态与备注不变；不能通过缩放旧记录数值、清空历史或新建习惯来模拟目标变化。其他习惯的定义及历史均应保持不变。

已实测路径为Coffee每日至多目标从2杯改为3杯，先前的2026-10-15历史更正保留。保存、终止进程、重开和导出后，整个22天窗口的强度按新目标计算，19条显式Coffee记录不变；完整5习惯89条记录及对象身份另行核对。该证据不覆盖目标方向切换、周期改变、取消编辑或零目标边界，不能把这些尚未核验的行为推定为同一规则。

证据范围：每日至多2杯的22天历史、零/缺省/跳过及备注、一次历史更正后的重启和导出已在参考App核验。至少目标与零目标的公式已按冻结源码明确，但仍需独立设备样例。非每日数值窗口不受本文件覆盖，不得外推。
